# Exposure evidence operations

Exposure entries are explicit operator records. A globally routable IP observed on a scanned endpoint receives the owner-approved default classification `UNTRUST` and raises contextual severity one level, with low confidence and an explicit note that service reachability is unverified. This default is a risk assumption, not verified Internet accessibility. A validated endpoint-specific operator assessment overrides it. Use an authorized external network vantage point or a reviewed and dated network control to record confirmed evidence. DNS, reverse DNS, DMZ, NAT, proxy address or scan location alone do not prove reachability.

Operators may submit evidence with its method, source, justification and confidence. An administrator reviews the cited evidence and marks it validated. A pending proposal never affects contextual risk. A validated record takes precedence over the public-IP default. To withdraw a finding, set the current record to `unknown` or replace it with newly reviewed evidence; historical scan snapshots stay unchanged.

Run migrations using the deployment's documented install/update command. Before a deployment, back up the database and storage volume. Verify the schema head with `alembic heads` in the backend environment and check that the migration path has one head after all independently developed ticket branches are integrated. If the upgrade fails, restore the pre-upgrade database backup; do not delete old run/report files. No additional container capability, network permission or external service is required.

For a repeatable check, use test endpoints with globally routable, private, and documentation-only IPs. Confirm the public address is stored as assumed `UNTRUST`, while private/documentation IPs remain unknown. Record and validate a non-Internet exposure as ADMIN and confirm it overrides the default. Check that the grade and intrinsic severity remain unchanged and contextual risk follows `exposure-risk-v2`. Update exposure once more and verify that previous run snapshots still show their original states. No live connectivity probe is part of this check.
